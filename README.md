## DRAGON LEGEND ～勇者と魔竜王～

初代ドラゴンクエストにオマージュを捧げた、単一HTMLファイルのレトロRPGです。
名称・データ・素材はすべてオリジナルです。ブラウザで `dq/index.html` を開くだけで遊べます。

### あそびかた

- 矢印キー / WASD: 移動(スマホは画面の十字キー)
- Z / Enter / Space: はなす・けってい(スマホは A ボタン)
- X / Esc: メニュー・キャンセル(スマホは B ボタン)

### 内容

- フィールド探索(城・町・洞窟・魔王城)とランダムエンカウント
- ターン制コマンドバトル(たたかう / じゅもん / どうぐ / にげる)
- レベルアップ(最大Lv20)・呪文習得・武器/防具/盾の買い物・宿屋
- 洞窟にとらわれたセレナ姫の救出、王様への送り届け
- 二段階変身する魔竜王とのラストバトル、エンディング
- 王様に話しかけて「ぼうけんのしょ」へセーブ(localStorage)
